## 사용 방법

Tailwind CSS에서 다음과 같이 사용할 수 있습니다:

```tsx
// 배경색
<div className="bg-red-50">...</div>
<div className="bg-blue-60">...</div>

// 텍스트 색
<p className="text-purple-70">...</p>

// 테두리 색
<button className="border-green-40">...</button>
```
